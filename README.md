# 🔐 Caesar Cipher

A Python program for encrypting and decrypting text using the Caesar cipher technique.

## 📖 About the Project
The Caesar cipher is a classical substitution cipher that shifts letters through the alphabet by a specified number of positions.

## ✨ Features
- Encrypt and decrypt text using a shift value.
- Practise Python string manipulation and control flow.
